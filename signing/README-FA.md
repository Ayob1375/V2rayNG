# امضای APK (Signing Key)

این پوشه حاوی کلید امضای بیلدهای سفارشی این ریپو است.

## نکته امنیتی مهم

این کلید **عمومی** است (بخشی از ریپو عمومی). یعنی هر کسی از این کلید برای امضا می‌تواند استفاده کند و APKهایی با «هویت» این اپ بسازد. این رویه صرفاً برای اتوماسیون کامل بیلد بدون نیاز به GitHub Secrets انتخاب شده است.

اگر می‌خواهید کلید خصوصی و محرمانه داشته باشید:
1. فایل `ayob1375-v2rayng.keystore` و رمز آن را از منبع اصلی خودتان بردارید (نگاه کنید به `SETUP-FA.md`).
2. چهار Secret زیر را در تنظیمات ریپو بسازید:
   - `APP_KEYSTORE_BASE64`
   - `APP_KEYSTORE_PASSWORD`
   - `APP_KEYSTORE_ALIAS`
   - `APP_KEY_PASSWORD`
3. Workflow به‌طور خودکار در صورت وجود Secrets از کلید محرمانه شما استفاده می‌کند و به کلید عمومی این پوشه نیاز نخواهد داشت.

توجه: بعد از تغییر کلید امضا، نصب نسخه جدید روی نسخه قبلی فقط پس از حذف کامل اپ قبلی ممکن است (چون امضا عوض شده).
